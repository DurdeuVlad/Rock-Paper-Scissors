# Rock-Paper-Scissors

## Introduction

This project was built for the Cloudflight Coding Contest on March 31, 2023. It was all about solving a Rock-Paper-Scissors problem with increasing difficulty across multiple levels. I had to think fast, code faster, and deal with new constraints every time I passed a stage.

Nothing fancy here, just clean logic, quick decisions, and making sure the output matches what the contest needed.

## What It Does

Implements classic Rock-Paper-Scissors  
Handles different levels of complexity with smart logic  
Processes input and outputs moves according to the contest specs

## Tech Stack

Python

## How to Use

### 1. Clone the repo

```bash
git clone https://github.com/DurdeuVlad/Rock-Paper-Scissors.git
cd Rock-Paper-Scissors
```

### 2. Navigate to the level you want

Each level has its own folder:

- LEVEL1
- LEVEL2
- LEVEL3
- LEVEL4

### 3. Run the solution

```bash
python3 solution.py
```

Make sure you give it the right input like the contest rules expected.
